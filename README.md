# perforatoros-update
Утилита для обновления PerforatorOS.
Что делает: берёт "исходная версия"update.tar.gz и распаковывает в корень файловой системы.
Будет внедрено в PerforatorOS в версии 202610.1
---Установка на PerforatorOS 202610 и ниже:---
-Загружаем файл perforatoros-update с репозитория
-В терминале пишем: "sudo cp /путь/к/загруженному/файлу/ /usr/bin/perforatoros-update
-Всё!
